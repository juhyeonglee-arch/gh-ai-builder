GH AI 빌더 v0.8 (Rhino 8) — 말로 적으면 그래스호퍼 정의를 만들어 줘요

[처음 한 번]
1. 이 폴더를 원하는 곳에 풀어 두세요. (예: 문서\GH_AI)
2. Claude API 키 만들기: platform.claude.com 에 가입 → Billing에서 크레딧 충전(5달러면 충분)
   → API Keys에서 키 만들기 → 복사.
3. Rhino 8 명령창에 RunPythonScript 입력 → GH_AI_builder.py 선택.
4. 창 맨 아래 칸에 키를 붙여 넣고 [키 저장]. (키는 내 PC의 %APPDATA%\GH_AI\api_key.txt 에만 저장돼요)

[쓰기]
1. 예시를 고르거나 직접 적고 [새로 만들기]. 20초~2분 기다리면 그래스호퍼 캔버스에 노드가 생겨요.
   (그래스호퍼가 안 열려 있으면 자동으로 열어요. 새 정의는 기존 노드 아래쪽에 놓여요.)
2. 그룹 = 알고리즘 단계, 왼쪽 위 "설명" 패널 = 어떤 논리인지와 쓰는 법.
3. 바꾸고 싶으면 칸에 "루버 간격을 랜덤으로", "벽을 곡선으로" 처럼 적고 [지금 정의 고치기].
   지금 슬라이더 값은 그대로 두고 필요한 부분만 바꿔요.
4. 오류가 나면 오류 내용을 AI에게 다시 보내 자동으로 고쳐요(최대 2번).
5. 되돌리고 싶으면 그래스호퍼에서 Ctrl+Z.

[편하게 실행하기 (선택)]
Rhino → Options → Aliases → New: 이름 ghai, 명령 _-RunPythonScript "C:\...\GH_AI_builder.py"
그다음부터 명령창에 ghai 만 치면 돼요.

[비용]
한 번 만들 때 대략 0.1~0.45달러. 창의 기록에 매번 쓴 토큰이 표시돼요.

[문제가 생기면]
창 기록 칸의 글을 전부 복사해서 보내 주세요.

[무료로 쓰기 — API 키 없이] (v0.2)
1. Claude 스레드에 "이런 걸 만들어 줘"라고 적으면 Claude가 JSON(정의 설계도)을 줘요.
2. 그 JSON을 통째로 복사해서 빌더의 "만들고 싶은 것" 칸에 붙여 넣고 [새로 만들기].
   → 칸이 { 로 시작하면 API를 쓰지 않고 바로 캔버스에 지어요. 키도 필요 없어요.
3. 오류가 나면 기록 칸 글을 복사해서 스레드에 보내 주세요. 고친 JSON을 드려요.
4. 슬라이더를 바꾼 뒤 고치고 싶으면 [지금 정의 JSON 복사] → 스레드에 붙여 넣고 고칠 점을 적기.
5. [컴포넌트 목록 저장]을 한 번 눌러 바탕화면의 GH_컴포넌트목록.txt를 스레드에 올려 주면
   Claude가 내 PC에 있는 정확한 컴포넌트 이름으로 만들어서 오류가 줄어요.
examples 폴더에 바로 붙여 넣어 볼 수 있는 예시 JSON이 있어요.

[Rhino로 가져오기 — Bake] (v0.3)
그래스호퍼 화면의 형태는 미리보기라 Rhino에서 잡히지 않아요.
빌더 창의 [결과 Bake (Rhino로 넣기)]를 누르면 마지막 결과가 진짜 Rhino 객체로 들어가요.
레이어: GH_AI::정의 제목::부재 이름. Bake한 뒤 슬라이더를 바꿔도 이미 넣은 객체는 그대로예요.
(v0.4) 저장해 둔 .gh를 열었거나 창을 새로 띄웠어도 Bake가 돼요:
  캔버스에서 넣고 싶은 컴포넌트를 클릭(여러 개는 Shift)해 선택 → [결과 Bake].
  아무것도 선택하지 않으면 선이 더 나가지 않는 마지막 컴포넌트들을 자동으로 골라요.

[재료] (v0.5)
JSON에 재료가 적힌 부재는 Bake할 때 GH_AI::제목::재료::부재 레이어로 들어가고,
레이어에 색과 렌더 재질(GH_AI 강철/콘크리트/유리(반투명)/알루미늄/스팬드럴/목재/석재)이 붙어요.
정의 정보는 캔버스의 "GH_AI_DATA (지우지 마세요)" 패널에 같이 저장돼요.
→ .gh를 저장했다가 다시 열어도 [결과 Bake]·[지금 정의 고치기]·[JSON 복사]가 이어져요.

[블록] (v0.6)
같은 부재가 수천 번 반복되면(커튼월 유닛, 볼트, 노드) JSON의 "blocks"에 적힌 대로
원점의 원형 하나 → Rhino 블록 정의 1개, 위치 평면마다 블록 인스턴스로 Bake해요. 파일이 훨씬 가벼워요.
- 원형 부재는 그래스호퍼 화면에서 숨겨져 있어요(원점에 있으므로).
- 블록 이름: "정의 제목 - 블록 이름". 다시 Bake하면 같은 정의를 새 형태로 바꾸고 인스턴스를 더 넣어요.
- 블록 인스턴스 레이어: GH_AI::제목::블록::이름 / 블록 속 부재는 재료 레이어에 있어 색·재질이 따라와요.
- Rhino에서 블록 하나를 고치려면 BlockEdit.

[Bake 규칙] (v0.7)
- 아무것도 선택하지 않고 [결과 Bake] → 캔버스의 GH_AI 정의를 전부 Bake.
- 같은 정의를 다시 Bake → 그 정의로 예전에 넣은 객체·블록을 지우고 새로 넣어요(중복 없음).
- 컴포넌트를 선택하고 누르면 → 선택한 것만 Bake(이건 지우지 않고 더해요).

[미리보기] (v0.8)
중간 단계(점·선·작업면)는 그래스호퍼 미리보기에서 숨기고, 최종 부재와 미리보기용 노드만 보여요.
Bake한 Rhino 객체만 보려면 그래스호퍼 툴바의 눈 모양 아이콘으로 미리보기를 끄세요.

[새로 만들기 = 바꿔 짓기] (v0.9)
- [새로 만들기]를 누르면 캔버스에 있던 GH AI 정의를 지우고 같은 자리에 새로 지어요. 더 이상 2개, 3개로 쌓이지 않아요.
  예전 정의를 남겨 두고 싶으면 창의 "예전 GH AI 정의는 지우고…" 체크를 끄세요.
- Bake 결과는 정의 제목으로 구별해요. 같은 제목을 다시 Bake하면 예전 결과를 지우고 바꿔요.
  바꿔 지은 예전 정의(v0.7~0.8로 만든 것 포함)가 넣었던 객체도 다음 Bake 때 같이 지워요.
- 예시 05·06·07은 examples/이전판으로 옮겼어요. 타워는 08 하나만 쓰세요.
